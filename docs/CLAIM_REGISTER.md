# SERVARI Public Claim Register

This register is the public boundary for what the `servari-open` repository proves. It is intentionally conservative.

Labels:

- **VERIFIED** — inspectable in this repository and/or exercised by `python scripts/verify_all.py` (9 checks, `result: PASS (9/9)`) or CI.
- **PARTIAL** — present as a surface, skeleton, or documented pathway, but not fully proven by the public verification harness.
- **UNVERIFIED / NOT SHIPPED** — not present as runnable behavior in this repository.

## Current public claim

The strongest accurate public claim is:

> SERVARI is an open-source, local-first BYOM agentic OS shell with mechanical autonomy gates, a local runtime control surface, a single-process allow-listed executor that runs human-approved read-only actions exactly-once, a 51-agent file-backed local workspace surface, an append-only human verification queue, fail-closed health surfaces, and a metric-gated retention loop.

## Current public non-claim

The repository does not claim to ship a CONCURRENT autonomous multi-agent execution engine (swarm), a new foundation model, AGI, or third-party certification. The shipped executor (C20) is single-process and only runs allow-listed read-only/diagnostic actions; it is not the concurrent swarm of C15, which remains not shipped.
